# Gurunathan

Cinematic Portfolio of **Gurunathan V** — AI Engineer, Product Builder & Hackathon Competitor.

## 🚀 Features
- **Cinematic Apple-Inspired Interface**: Fluid typography, dark mode, glassmorphism, dynamic audio toggle.
- **3D Tilt Portrait Card**: Interactive laser scanlines, cursor tracking spotlight, scroll parallax & IntersectionObserver fade-in effects.
- **Mobile-First Responsive Architecture**: Engineered across 320px small phones to 4K Ultrawide displays.
- **Resume Distribution**: Production-ready PDF download integration across all major access points.
- **Project & Credentials Showcase**: Comprehensive interactive modals and verified Credly/LinkedIn integration.

## 🛠 Tech Stack
- HTML5, Vanilla CSS3, JavaScript (ES6+)
- Tailwind CSS CDN, Lucide Icons
- Vercel Deployment Configuration
